# VERBORA — Telegram Mini App для изучения английского

Маскот — Verbi. Идея и дизайн — Валерия. Техническое задание — SPEC.md (раздел 11, версия v1).

## Запуск

Нужен Node.js 20.19 или новее.

```bash
cd verbora
npm install
npm run dev            # локально: http://localhost:5173
npm run build          # сборка в verbora/dist
npm run check-content  # проверка JSON-контента
```

Netlify берёт настройки из `netlify.toml` в корне репозитория (base `verbora`, publish `dist`).

## Что собрано

- **Онбординг.** Экран-заставка, выбор языка объяснений (ua/ru, подсказка по `language_code` из Telegram, `uk` → `ua`), три экрана знакомства с Verbi, опрос (опыт, цель, минуты в день).
- **Диагностический тест** для «подзабыл» и «уверенный уровень»: 15 адаптивных вопросов (верно → сложнее, ошибка → проще). Результат — стартовый уровень и карта тем. Уровни ниже стартового отмечаются пройденными.
- **Серпантин** на главном экране. Каждый уровень — свой путь, кружок = урок, юниты — участки своего цвета, в конце юнита чекпоинт. Состояния: пройден, текущий (пульсирует, рядом Verbi), закрыт, «освежить» 🔁. Закрытый юнит можно «перепрыгнуть», сдав чекпоинт. В конце уровня финальный тест (25 заданий) и переход на следующий уровень. Юниты без файла контента показаны как «Незабаром».
- **Шапка прогресса.** Уровень и процент, Verbi держит табличку с процентом и радуется, когда он растёт. Рядом стрик и XP. Миссии дня.
- **Плеер урока** проигрывает `content/<уровень>/unit-XX.json`:
  1. **Разминка «Згадаймо / Вспомним»:** напоминание (заметка, формула и пример прошлого правила) и задания из `recap`. Кнопка «Пам'ятаю ✓» пропускает разминку. Если `recap` не задан, движок сам берёт правило и 2 задания прошлого урока. Если в прошлой теме были ошибки, разминка берёт задания из «работы над ошибками».
  2. **Правило:** формула, объяснение, примеры с 🔊, сравнение с родным языком.
  3. **Задания.** Все 15 типов из раздела 12: `choose`, `fill`, `build`, `fix`, `listen`, `translate`, `ipa`, `match`, `wordbank`, `define`, `associate`, `brackets`, `reading`, `picture` и `write` (для `write` пока заглушка, проверка ИИ в v2).
  4. **Разбор ошибки** сразу после ответа: правильный ответ и `explain`. Задания с ошибкой повторяются один раз в конце урока.
  5. **Итог:** XP, стрик, точность, список ошибок с объяснениями, новые бейджи.
- **Чекпоинт** — тот же плеер по `checkpoint[]`. Нужно 80% правильных ответов. Сданный чекпоинт открывает юнит и следующий участок пути.
- **Проверка ответов** по SPEC §12: без учёта регистра, лишних пробелов и знака в конце; `’` и `'` считаются одинаковыми; принимаются варианты из `accept[]`.
- **Слова.** Словарь юнитов: IPA, 🔊, перевод, пример. Карточки с интервальным повторением (коробки Лейтнера: 0/1/2/4/8/16/32 дня).
- **Карта грамматики:** 🟢 знаю, 🟡 «плавает», 🔴 пробел, 🔒 закрыто, по темам (`topic`) каждого юнита. Отсюда же «работа над ошибками».
- **Мини-курс «Как читать транскрипцию».** 5 уроков, финальный челлендж и бейдж «Читаю транскрипцию 🏅». Интерактивная таблица звуков: тап по символу озвучивает примеры.
- **Профиль:** стрик по дням недели, XP, прогресс по уровням, точность по темам, бейджи (есть скрытые). **Настройки:** язык ua/ru (прогресс сохраняется), имя, звук, светлая и тёмная тема, сброс.
- **Маскот:** 21 эмоция из `public/assets/mascot/`. Исходные PNG весили 26 МБ, они переведены в webp по 480 px (около 940 КБ). Анимации на CSS: парение, появление, подпрыгивание, покачивание при ошибке, конфетти и звёздочки. Эмоции привязаны к событиям: правило → «объясняет», аудирование → «слушает», верно → «правильно», 5 подряд → «серия 🔥», ошибка → ободряющая, 2 ошибки подряд → «поддержка», итог → «празднует», бейдж, новый уровень, сгоревший стрик → «грустит».
- **Telegram:** `ready/expand`, имя пользователя, haptic feedback, нативная кнопка «Назад». В обычном браузере всё тоже работает.
- **Озвучка:** если в контенте заполнено поле `audio`, играет mp3, иначе работает Web Speech API (британский голос, есть замедленный режим 🐢).

## Контент

```
content/
  levels.json            # карта уровней и юнитов серпантина (§13)
  a1/unit-01.json        # юнит: правило, слова, уроки, чекпоинт (§12)
  diagnostic.json        # банк вопросов диагностики A1–C1
  topics.json            # названия тегов topic для карты грамматики
  extra/transcription.json, extra/ipa-sounds.json
```

Чтобы добавить юнит, положите файл `content/a1/unit-02.json` с `id: "a1-u02"`. Он сам встанет на своё место серпантина по `levels.json`, правка кода не нужна. `npm run check-content` проверяет обязательные поля, уникальность id, наличие ответа среди вариантов, пропуски `___` и нормы объёма (8–10 заданий в уроке, 10–12 в чекпоинте).
