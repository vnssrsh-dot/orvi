# orvi.

**Порядок створює свободу.**

orvi. — Telegram Mini App для личных и совместных задач. Интерфейс на украинском языке.

## Прототип

`prototype/index.html` — интерактивный кликабельный прототип интерфейса. Это один HTML-файл без сборки: откройте его в браузере. Данные демонстрационные и хранятся только в открытой вкладке.

Над телефоном есть переключатель «Демо-дані / Новий користувач» и кнопка «Бібліотека іконок». Справа показана лента Telegram-бота: его сообщения строятся из текущих данных прототипа.

### Что есть в прототипе

- **Навигация.** Три раздела: Головна, Особисті, Спільні. Настройки открываются по шестерёнке.
- **Головна.** Общий обзор задач и подзадач со всех досок без дубликатов. Для нового пользователя показаны три шага онбординга.
- **Доски.** Создание доски, иконка и подложка из библиотеки (158 иконок), поиск, «Обрані», «Архів» и «Кошик» (восстановление в течение 14 дней).
- **Этапы.** Вертикальные этапы: создание, своя иконка, тип статуса, перестановка перетаскиванием и кнопками, удаление с переносом задач или вместе с ними.
- **Задачи.** Перетаскивание внутри этапа и между этапами (долгое нажатие на телефоне), отмена последнего действия. В карточке задачи: срок, приоритет, этап, метки, ответственный, соучастники, файлы, комментарии.
- **Подзадачи.** У каждой свой исполнитель, срок и статус. Выполненные подзадачи не закрывают основную задачу.
- **Совместная работа.** Роли «Власник», «Редактор», «Спостерігач». Приглашение по @username с выбором роли и отдельная ссылка-приглашение для каждой роли.
- **Уведомления.** Для каждой доски: полное отключение, ежедневная подборка задач в выбранное время и дни, напоминания о сроках в точное время, выбор событий. Общие тихие часы.
- **Оформление.** Светлая и тёмная тема.

## Открыть прототип в Telegram

`docs/index.html` — та же версия прототипа, но для запуска внутри Telegram. Приложение занимает весь экран, без рамки телефона и панели бота. Оно разворачивается на весь экран, отключает свайп вниз и показывает имя пользователя из Telegram.

1. **GitHub Pages.** Settings → Pages → Build and deployment: Source «Deploy from a branch», ветка с этими файлами, папка `/docs` → Save. Через минуту-две появится адрес вида `https://vnssrsh-dot.github.io/orvi/`. На бесплатном плане Pages работает только для публичного репозитория.
2. **BotFather.** `/mybots` → ваш бот → Bot Settings → Menu Button → указать этот адрес. Или `/newapp`, чтобы приложение открывалось по ссылке `t.me/<бот>/<имя>`.

Данные в прототипе демонстрационные и хранятся только на устройстве. Общих досок между людьми и настоящих сообщений бота пока нет: для этого нужен сервер.

## Что учесть при сборке в Telegram

- Отключить вертикальные свайпы (`Telegram.WebApp.disableVerticalSwipes()`), чтобы перетаскивание вниз не сворачивало приложение.
- Включить подтверждение закрытия (`enableClosingConfirmation()`), чтобы приложение не закрывалось случайно.
- Подборки и напоминания планировать на сервере бота по сохранённым настройкам каждой доски и пересчитывать их при смене срока, исполнителя или статуса задачи.
