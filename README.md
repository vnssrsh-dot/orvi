# orvi.

**Порядок створює свободу.**

orvi. — Telegram Mini App для личных и совместных задач. Интерфейс на украинском языке.

## Прототип

`prototype/index.html` — интерактивный кликабельный прототип интерфейса. Это один HTML-файл без сборки: откройте его в браузере. Данные демонстрационные и хранятся только в открытой вкладке.

Над телефоном есть переключатель «Демо-дані / Новий користувач» и кнопка «Бібліотека іконок». Справа показана лента Telegram-бота: его сообщения строятся из текущих данных прототипа.

### Что есть в прототипе

- **Навигация.** Три раздела: Головна, Особисті, Спільні. Настройки открываются по шестерёнке.
- **Головна.** Общий обзор задач и подзадач со всех досок без дубликатов. Для нового пользователя показаны три шага онбординга.
- **Доски.** Создание доски, иконка и подложка из библиотеки (158 иконок), поиск, «Обрані», «Архів» и «Кошик» (восстановление в течение 14 дней).
- **Этапы.** Вертикальные этапы: создание, своя иконка, тип статуса, перестановка перетаскиванием и кнопками, удаление с переносом задач или вместе с ними.
- **Задачи.** Перетаскивание внутри этапа и между этапами (долгое нажатие на телефоне), отмена последнего действия. В карточке задачи: срок, приоритет, этап, метки, ответственный, соучастники, комментарии.
- **Подзадачи.** У каждой свой исполнитель, срок и статус. Выполненные подзадачи не закрывают основную задачу.
- **Совместная работа.** Роли «Власник», «Редактор», «Спостерігач». Приглашение по @username с выбором роли и отдельная ссылка-приглашение для каждой роли.
- **Уведомления.** Для каждой доски: полное отключение, ежедневная подборка задач в выбранное время и дни, напоминания о сроках в точное время, выбор событий. Общие тихие часы.
- **Оформление.** Светлая и тёмная тема.

## Приложение в Telegram (бот @orvi_task_bot)

Рабочая версия — это один Cloudflare Worker (`server/`). Он отдаёт само приложение (`docs/`), обрабатывает его запросы, принимает сообщения бота и по расписанию рассылает подборки и напоминания. Данные хранятся в базе Cloudflare D1.

- **Первый запуск.** Чистый аккаунт нового пользователя с онбордингом. Дальше открываются его доски, задачи и настройки с любого устройства.
- **Совместные доски.** Все участники видят одни и те же данные. Изменения других людей подтягиваются при открытии приложения и раз в 15 секунд. Если двое правят одно и то же одновременно, правки объединяются: комментарии, подзадачи и разные поля не затирают друг друга.
- **Права.** Права проверяются на сервере. Наблюдатель не может ничего изменить даже в обход интерфейса, а единственный владелец не может покинуть доску.
- **Приглашения по @username.** Бот присылает сообщение с ролью и кнопкой «Відкрити запрошення». Бот может написать только тому, кто хотя бы раз запускал @orvi_task_bot; иначе приложение предложит отправить ссылку.
- **Ссылки-приглашения.** Отдельная ссылка для каждой роли вида `t.me/orvi_task_bot?start=join_…`. Ссылка действует 7 дней, по ней может присоединиться до 10 человек, и владелец может её перевыпустить.
- **Уведомления бота.** Назначения, комментарии, смена срока или статуса, передача на проверку, новые участники. Подборки и напоминания приходят в точное время по настройкам каждой доски с учётом часового пояса и тихих часов, без повторов. Если срок изменится, старое напоминание не придёт.
- **Защита.** Каждый запрос подписан Telegram, сервер проверяет подпись токеном бота.

### Как выложить на Cloudflare

Понадобятся бесплатный аккаунт Cloudflare и Node.js 18 или новее.

```bash
cd server
npx wrangler login                       # вход в Cloudflare в браузере
npx wrangler d1 create orvi              # создаст базу и покажет database_id
```

1. Укажите `database_id` своей базы в `server/wrangler.toml` (сейчас там id базы orvi в аккаунте владельца).
2. Добавьте секреты. Каждая команда попросит ввести значение:
   ```bash
   npx wrangler secret put BOT_TOKEN        # токен бота из @BotFather
   npx wrangler secret put WEBHOOK_SECRET   # придумайте строку из латиницы и цифр, 20+ символов
   ```
3. Выложите: `npx wrangler deploy`. В конце будет адрес вида `https://orvi.<ваш-аккаунт>.workers.dev`.
4. Откройте один раз в браузере `https://orvi.<ваш-аккаунт>.workers.dev/setup?secret=<WEBHOOK_SECRET>`. Должно появиться «orvi. готово ✅». Это подключает бота к серверу и ставит кнопку меню «orvi.».
5. Напишите боту @orvi_task_bot `/start` и нажмите «Відкрити orvi.».

Таблицы в базе создаются автоматически при первом запросе. После изменений в коде достаточно снова выполнить `npx wrangler deploy`.

### Локальная проверка

`server/.dev.vars` с тестовыми значениями `BOT_TOKEN`, `WEBHOOK_SECRET` и `TG_API` (адрес подставного Telegram API), затем `npx wrangler dev --local --test-scheduled`. Файл `.dev.vars` в репозиторий не попадает.
